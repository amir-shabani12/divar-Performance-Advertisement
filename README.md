# 📊 افزونه کروم استخراج خودکار آمار و عملکرد آگهی‌های دیوار
### Divar Ads Performance Exporter (Chrome Extension - Manifest V3)

یک افزونه کاربردی، سبک و پرسرعت برای گوگل کروم جهت استخراج خودکار تمام آمار و ارقام عملکرد آگهی‌های پنل کاربری دیوار به فایل اکسل (`CSV` با فرمت استاندارد فارسی).

---

## ✨ ویژگی‌های کلیدی

- ⚡ **سرعت فوق‌العاده:** پردازش و استخراج ده‌ها آگهی در کمتر از ۱۰ ثانیه.
- 🎯 **استخراج دقیق آمار عملکرد:**
  - عنوان آگهی
  - کل نمایش‌ها (Impressions)
  - کل بازدیدها (Views)
  - کل تماس‌ها (Calls)
  - کل نشان‌کردن‌ها (Bookmarks)
  - جایگاه لحظه‌ای در شهر و دسته‌بندی
  - قیمت، وضعیت انتشار و تاریخ/شهر آگهی
- 🏢 **سازگاری جامع:** پشتیبانی هم‌زمان از **حساب‌های شخصی** و **پنل‌های فروشگاهی/کسب‌وکار** دیوار.
- 📑 **خروجی استاندارد اکسل:** ذخیره با انکودینگ `UTF-8 with BOM` جهت نمایش کاملاً خوانا و بدون به‌هم‌ریختگی حروف فارسی و اعداد در نرم‌افزار Microsoft Excel.
- 🔒 **حفظ حریم خصوصی:** پردازش ۱۰۰٪ محلی در مرورگر کاربر و بدون ارسال داده‌ها به هیچ سرور جانبی.

---

## 🚀 راهنمای نصب در مرورگر گوگل کروم

1. مخزن را دانلود یا کلون کنید:
   ```bash
   git clone https://github.com/your-username/divar-ads-exporter.git
   ```
2. مرورگر **Chrome** را باز کنید و به آدرس زیر بروید:
   ```text
   chrome://extensions
   ```
3. گزینه **Developer mode** (حالت توسعه‌دهنده) را در گوشه بالا سمت راست فعال کنید.
4. روی دکمه **Load unpacked** (بارگذاری بسته بازنشده) در بالا سمت چپ کلیک کنید.
5. پوشه پروژه (`divar-exporter`) را انتخاب نمایید.

## 📖 نحوه استفاده

1. وارد سایت [دیوار (divar.ir)](https://divar.ir) شوید و اطمینان حاصل کنید که وارد حساب کاربری خود شده‌اید.
2. به بخش آگهی‌های من (`divar.ir/my-divar/my-posts`) بروید.
3. روی آیکون افزونه در نوار ابزار کروم کلیک کنید.
4. دکمه **«شروع استخراج»** را بزنید.
5. پس از چند ثانیه، فایل اکسل به صورت خودکار در پوشه Downloads سیستم شما ذخیره خواهد شد.
